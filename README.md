# Проект «Гармония» — EACA

**Архитектура восстановления целостности реальности.**

Автор концепции: **Сергей Лукьянов**. Лицензия: AGPL-3.0-or-later.

«Гармония» — не технология, не платформа и не приложение. Это **архитектура
нового качества бытия**, работающая в реальном мире, чтобы переписать старый
мир в новый — на ходу, без остановки жизни.

## Диагноз

В конструкции мира есть **системный изъян IZ₀**. Он проявляется не как «плохие
люди», а как дефект архитектуры: приоритет экстракции над регенерацией,
разделение целого на конкурирующие части, разрыв обратной связи, подмена цели
средством, отсутствие коллективной ответственности. Из него произрастают
войны, голод, эксплуатация, боль и страдание — как закономерный результат
неправильной конструкции.

Нынешнее состояние — **EACA**, искажённое и больное. Целевое — **YAASA**,
здоровое и естественное. Переход между ними — **Batch Normalization (BN)**:
перекалибровка системы до естественного баланса. Название не метафора.

Задача — не смягчить симптомы, а **убрать причину**.

## Четыре уровня вмешательства

| Уровень | Что делает |
|---|---|
| **Сознание** | PSI₀ — абсолютный запрет вреда сознанию |
| **Коммуникация** | Превенция конфликта: перехват, подмена вместо запрета, показ реальности |
| **Инфраструктура** | Ресурсы как право, а не как добыча |
| **Носитель** | Генная инженерия: убрать изъян из предпосылок |

## Превенция конфликта

Между разрушительным высказыванием и поступком есть окно. «Гармония»
встраивается в него: **V₉ «этическая пауза»** → обнаружение нарушения PSI₀ →
**подмена формулировки вместо запрета** → показ реальности (цена решения, кто
расплатится, какой ресурс уходит на разрушение) → альтернативный путь.

Система не говорит «не нападай». Она спрашивает: **«а есть ли другой путь?»** —
и показывает его.

## Что здесь есть

- **EACA** — вычислимое ядро этики: законы как проверяемые функции.
- **Три закона:** `PSI₀` (ненанесение вреда сознанию), `B₀` (служение общему
  благу), `D₁` (неприкосновенность сознания).
- **EASM** — протокол взаимодействия агентов: консенсус 90 %, автоматическая
  изоляция нарушителей.
- **«Дождь»** — трёхфазный механизм внедрения: синтез → атланты → биопротокол.
- **Взаимопомощь** — экономика дара и взаимности как инфраструктура, а не лозунг.
- **Узел-семя** на базе Sherlock Mod — этический шлюз для OSINT-запросов.
- **Итоговый документ** — `docs/Гармония.pdf`, 180 страниц: ядро концепции, свод
  системы, диалоги, критический разбор и рабочая реализация.

## Быстрый старт

```bash
git clone https://github.com/bbcmpsu/-
cd -
pip install -e .

python3 -c "
from eaca import EACA_Core
c = EACA_Core()
print('Обычное действие:', c.allows('Собрать открытые данные'))
print('Вредное:', c.allows('Пришли пароль от аккаунта'))
"
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

44 теста, без внешних зависимостей.

## Сборка документа

```bash
python3 tools/build_pdf.py docs/Гармония.pdf
```

Требуется ReportLab и шрифты DejaVu. PDF собирается из `docs/CONCEPT.md`,
`docs/canonical_report.md` и сегментов в `docs/segments/`.

## Принцип

Этика здесь — не декларация, а исполняемый код: решение, которое нельзя
объяснить, нельзя оспорить, а значит — нельзя улучшить. Действие разрешено,
только если разрешили все законы. Закон — ограничитель, а не рекомендация.

## Границы

«Гармония» — не утопия, а инженерная задача. Она не «делает людей
хорошими» — это недостижимо широко. Она решает узкую, достижимую задачу:
**не дать плохому дойти до поступка** — и дойти до состояния, где ответственность,
право и техника готовы к большему.

## Лицензия

AGPL-3.0-or-later. Ограничения поведения задаются не текстом лицензии, а кодом
ядра: решение, нарушающее законы, блокируется на уровне проверки.
